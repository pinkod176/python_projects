# Zeboogie — интернет-магазин на товарах сообщества ВКонтакте

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Zod · Lucide.
Из VK берутся **только товары** (название, описание, цена, фото, подборки). Интерфейс, тексты бренда (`src/content/brand.ts`) и дизайн — собственные.

## Быстрый старт
```bash
cd zeboogie-shop
npm install
cp .env.example .env.local      # по умолчанию VK_MODE=demo
npm run dev                     # http://localhost:3000
```
Проверки: `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`.

## Демо- и рабочий режим
| `VK_MODE` | Источник | Хранилище |
|---|---|---|
| `demo` (по умолч.) | `src/lib/vk/demo/market.json` — **тестовые** данные в формате ответов VK API (28 товаров: названия и цены сняты со скриншотов витрины, фото — временные вырезки низкого разрешения) | `data/catalog.demo.json` |
| `live` | VK API | `data/catalog.vk.json` |

Файлы снимков разные, поэтому демо-товары **никогда не смешиваются** с реальными. В демо-режиме сайт показывает плашку, закрыт от индексации (`noindex`, `robots`, пустой sitemap).

## Подключение сообщества
1. Получите токен (любой один из вариантов):
   - **Ключ сообщества**: Управление → Настройки → Работа с API → Ключи доступа, право **«Товары»** (и «Сообщения» для автоотправки заказов);
   - **Сервисный ключ** VK-приложения (достаточно для чтения публичных товаров).
2. В `.env.local`:
   ```
   VK_MODE=live
   VK_GROUP=zeboogie
   VK_ACCESS_TOKEN=...
   SITE_URL=https://ваш-домен
   SYNC_SECRET=<openssl rand -hex 32>
   ```
3. В сообществе должен быть включён раздел «Товары».
4. `npm run sync` — первая загрузка (если снимка нет, она произойдёт и автоматически при первом открытии сайта).

> Модуль VK написан по документации (`groups.getById`, `market.get`, `market.getAlbums`, `messages.send`) и проверен на подменённом `fetch`, но **с реальным сообществом не запускался** (в среде разработки VK был недоступен). Поля `variants`/`albums_ids` разбираются терпимо и подтверждаются только на живых данных.

## Синхронизация
- Первая загрузка: автоматически или `npm run sync`.
- Обновление: фоново при открытии сайта, если снимок старше `SYNC_TTL_MINUTES` (stale-while-revalidate), и по расписанию: `curl -X POST -H "Authorization: Bearer $SYNC_SECRET" https://домен/api/sync` (cron/планировщик).
- Новые товары добавляются, изменённые обновляются, дубли исключены (ключ `owner_id_item_id`). Товары, исчезнувшие из VK, помечаются `removed` (страница показывает «больше недоступна», в каталоге/sitemap их нет); вернувшиеся восстанавливаются. Пустая выдача VK при непустом каталоге **не стирает** товары.
- Лимиты VK: запросы идут по очереди (≤3/с), при кодах 1/6/9/10, таймаутах и 5xx — повтор с экспоненциальной паузой. Журнал: `data/sync-log.jsonl` + JSON-логи в stdout (секреты маскируются).

## Заказы
Магазин не принимает оплату. Заказ — это сообщение сообществу:
- Сайт проверяет наличие позиций по каталогу и собирает текст заказа.
- Если задан `ORDER_NOTIFY_VK_USER_ID` и ключ сообщества с правом «Сообщения» — сервер отправляет сообщение сам, и только после ответа VK сайт пишет «Заказ отправлен».
- Иначе сайт честно пишет «заказ подготовлен, но **не отправлен**» и даёт текст + ссылку на сообщения сообщества. Корзина очищается только после подтверждения покупателем.
- Онлайн-оплата не реализована (нужен внешний платёжный сервис).

## Переменные окружения
См. `.env.example`. Секреты (`VK_ACCESS_TOKEN`, `SYNC_SECRET`) используются только на сервере; префикса `NEXT_PUBLIC_` нет, в клиентском бандле их нет (проверено поиском по `.next/static`).

## Структура
```
src/app/            страницы и API (/, /catalog, /product/[slug], /checkout, /favorites, /about, /api/*)
src/components/     ui, layout, home, catalog, product, cart, checkout
src/lib/vk/         client (лимиты/повторы), api, schemas (zod), mapper, source (demo|live), messages
src/lib/catalog/    sync, diff, store (файловый снимок), query (фильтры/сортировка/поиск), service (чтение для UI)
src/content/        тексты бренда (не из VK)
vk-mcp/             (в корне репозитория) необязательный MCP-сервер для чтения товаров VK из Claude
```
Хранилище — файловый снимок за узким интерфейсом (`store.ts`). Для нескольких серверов/serverless замените реализацию на PostgreSQL (Prisma) — остальной код не меняется. Prisma/PostgreSQL здесь намеренно не подключены: для одного сервера они избыточны.

## Что нужно донастроить
Токен VK; `SITE_URL`; расписание для `/api/sync`; `ORDER_NOTIFY_VK_USER_ID` (автоотправка заказов); контакты `SHOP_EMAIL`/`SHOP_PHONE`; при деплое на serverless — внешнее хранилище вместо `data/`.
