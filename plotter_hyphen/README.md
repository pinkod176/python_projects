# Переносы для плоттера

Утилита с окном. Она готовит русский текст для программы плоттера (Kvenjoy / KenjoyDraw):
разбивает текст на строки нужной ширины и **переносит слова по правилам русского языка**.
Ширина считается по штрихам того же шрифта `.gfont`, которым пишет плоттер, включая сам дефис.
Результат с явными переводами строк вставляется в программу плоттера вместо исходного текста.

Почему утилита отдельная: KenjoyDraw поставляется только в собранном виде, её классы
зашифрованы (`core`, `bate` расшифровывает `KvenjoyEncrypt.dll`). Встроить переносы внутрь
программы нельзя, не взламывая её защиту. Утилита в программу не вмешивается. Каждую букву,
и дефис тоже, программа рисует сама из своего шрифта, поэтому G-code и траектории символов
не меняются. Утилита решает только, где кончается строка.

## Запуск

**Готовый exe:** `PlotterHyphen.exe` — один файл, Python не нужен. Его собирает GitHub Actions
(workflow «plotter_hyphen — Windows exe», артефакт `PlotterHyphen-exe`) при каждом изменении
папки `plotter_hyphen`. Удобно положить exe в папку программы плоттера: шрифт из `gcodeFonts`
подхватится сам.

**Собрать exe самому** (Windows, Python 3.10+): `build_exe.bat`. Он ставит зависимости
в `.venv`, прогоняет тесты, собирает `dist\PlotterHyphen.exe` через PyInstaller и проверяет
собранный exe.

**Из исходников:** `run_gui.bat` (при первом запуске ставит `pyphen` и `PySide6` в `.venv`)
или `pip install -r requirements.txt` и `python hyphen_gui.py`.

Самопроверки (работают и в exe; результат пишется в файл, потому что у exe нет консоли):

```
PlotterHyphen.exe --selftest  папка [шрифт.gfont]   -> папка\selftest.txt
PlotterHyphen.exe --smoke-gui папка                 -> папка\smoke.txt + window.png
```

## Как пользоваться

1. **Шрифт .gfont.** «Открыть…» → файл из `gcodeFonts` программы плоттера (например,
   `Мой почерк.gfont`). Если утилита лежит в папке программы плоттера, шрифт найдётся сам.
2. **Ширина строки, мм:** ширина области текста на листе.
3. **Калибровка** (один раз для шрифта и размера букв в программе плоттера). Напишите в
   KenjoyDraw эталонную строку («Съешь же ещё этих мягких французских булок») тем же шрифтом
   и размером. Измерьте её длину на бумаге или по линейке программы, от левого края первой
   буквы до правого края последней, и введите в поле «Её длина на бумаге». Без калибровки
   ширина строки считается примерно.
4. Вставьте текст слева. Справа на вкладке «Текст для программы плоттера» появится результат.
   На вкладке «Предпросмотр» те же строки нарисованы штрихами шрифта: красная линия —
   допустимая ширина с запасом, пунктир — ширина строки.
5. «Копировать результат» → вставьте текст в KenjoyDraw.

**Запас, %** (по умолчанию 3 %) делает строки чуть короче расчётной ширины. Тогда программа
плоттера не перенесёт хвост строки сама из-за неточности расчёта. Если она всё-таки переносит,
увеличьте запас или поправьте «межбуквенный интервал» и «пробел» в группе калибровки
(единицы шрифта; по умолчанию 35 и 110, как в предпросмотре `gfont_converter`).

## Включение и выключение переносов

Флажок **«Переносы»** в окне, включён по умолчанию. Если его выключить, слова переходят на
новую строку целиком, как раньше. Состояние флажка и остальные настройки сохраняются
в `%APPDATA%\PlotterHyphen\settings.json`.

Если в шрифте нет символа `-`, переносы с дефисом отключаются сами (об этом написано рядом
с именем шрифта).

## Правила

Слоги даёт `pyphen` со словарём `ru_RU` (TeX-паттерны). Поверх них `hyph/rules.py` применяет
правила:

- перенос только по границе слогов, в каждой части есть гласная: ма-ши-на, до-ро-га;
- минимум 2 буквы остаются на строке и 2 переходят: не «а-втор», не «обеда-ть»;
- ь, ъ, й не отрываются от предыдущей буквы: паль-то, подъ-езд, чай-ка;
- граница приставки и корня не нарушается: под-ход, раз-бить, рас-сказ, воз-дух;
- двойные согласные разрываются: кас-са;
- слово с дефисом переносится по дефису, дефис остаётся вверху: «кто-» / «то»;
- не переносятся числа, аббревиатуры из заглавных, слова с латиницей или цифрами,
  слова короче 5 букв;
- знаки препинания вплотную к слову едут вместе со своей частью: открывающие («, ( )
  остаются наверху, закрывающие (, . ! ? » ) уходят вниз; строка не начинается со знака.

Раскладка (`hyph/layout.py`): если слово не помещается, выбирается **самое правое** место
переноса, при котором «часть + дефис» ещё влезает в строку. Если такого места нет, слово
переходит целиком. Слишком длинный остаток переносится снова. Абзацы и пустые строки
сохраняются.

## Проверка

```
python -m pytest tests            # все тесты (окно проверяется без экрана)
python check_examples.py          # примеры из задания, условная ширина букв
python check_examples.py "C:\...\gcodeFonts\Мой почерк.gfont"   # ширины настоящего шрифта
```

## Файлы

| Файл | Что делает |
|---|---|
| `hyph/rules.py` | места переноса по правилам русского языка |
| `hyph/layout.py` | разбиение текста на строки с выбором самого правого переноса |
| `hyph/metrics.py` | ширина текста по bbox глифов `.gfont` + интервал + пробел |
| `hyph/gfont.py` | чтение `.gfont` (формат как в `gfont_converter`) |
| `hyph/settings.py` | настройки и калибровка (мм на единицу шрифта) |
| `hyph/gui.py`, `hyphen_gui.py` | окно |
| `hyph/selftest.py` | самопроверки `--selftest` / `--smoke-gui` для exe |
| `PlotterHyphen.spec`, `build_exe.bat` | сборка exe (PyInstaller) |
| `check_examples.py` | проверка на примерах |
| `tests/` | тесты pytest |
